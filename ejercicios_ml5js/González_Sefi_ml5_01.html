Explicación de cómo funciona el código

En este proyecto he desarrollado una página web que permite activar la cámara del móvil y aplicar un modelo de inteligencia artificial en tiempo real. El sistema comienza cuando el usuario pulsa el botón de inicio, ya que los navegadores exigen una acción directa para conceder permisos de acceso a la cámara por motivos de seguridad y privacidad.

Una vez pulsado el botón, el script utiliza getUserMedia() para solicitar acceso a la cámara del dispositivo y mostrar la imagen en el elemento video. Después ajusta el tamaño del canvas al tamaño real del vídeo, de forma que los dibujos que se realicen encima coincidan exactamente con la imagen capturada.

A continuación, el programa carga el modelo preentrenado COCO-SSD mediante la librería ml5.js. Este modelo ya ha sido entrenado previamente para reconocer objetos comunes, por lo que no es necesario entrenar nada desde cero. Simplemente se inicializa y queda preparado para analizar lo que ve la cámara.

Finalmente, el script ejecuta un bucle continuo de detección que analiza cada fotograma del vídeo. Cuando encuentra objetos, dibuja rectángulos alrededor de ellos, muestra su nombre y el porcentaje de confianza, y además selecciona el objeto con mayor probabilidad como “Mejor detección”. De esta manera, la inteligencia artificial funciona en tiempo real directamente en el navegador.
